# Human checkpoint reports

This directory contains the reports presented at mandatory human checkpoints.

Name each report by development progress:

```text
<progress-id>-<short-subject>-human-review.md
```

Use the roadmap identifier first (`T0`, `T1`, `F1`, `T2`, `F2`, or `T5`) so reports sort by development progress. Each report records the verified repository commits, tests, unresolved risks, decision requested, human response, and resulting authorization boundary.
